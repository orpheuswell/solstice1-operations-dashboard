Network health guide

How to tell whether Chain 1404 is working

RPC: lets wallets and apps talk to the blockchain. Explorer: lets people look up transactions and blocks. Node: independently follows and checks the chain.

One website being unavailable does not automatically mean the whole network is offline. Compare more than one independent source and check whether new blocks are appearing.

Status: Not automatically checked by this website. Use the linked services above for current evidence. Never treat an old timestamp as live confirmation.

🖥️ Run Your Own Community Node

Independent nodes help reduce reliance on any single infrastructure provider. This is a learning resource, not a promise that installation will be easy or production-ready.

Beginner guide

What does a node do?

A node checks and shares blockchain information with other nodes. Running independently can support resilience and give operators their own way to verify network data.

A node is different from a mining pool. Running one does not automatically generate mining rewards.

Check requirements

Before you install

Check Linux compatibility, available RAM, storage, connectivity, security and current release notes. The published stack has outstanding fresh-install and Mainnet qualification work.
